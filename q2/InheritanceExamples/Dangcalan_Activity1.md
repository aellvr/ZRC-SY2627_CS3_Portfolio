1. What is/are the parent class/es of the Programmer class in the video?
The direct parent class is Employee, and the top base class is Person. In the video, Employee inherits from Person, 
and Programmer inherits from Employee because a programmer is a type of employee.


2. If you were to add a new role called Intern, where would you place it in the inheritance hierarchy? Why?
I would place Intern as a child class under Employee, right next to Programmer. This is because an intern is a "type of" employee, 
meaning they should automatically share regular worker traits while letting you add unique rules like a temporary end date.
